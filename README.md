Идея нашего проекта состоит в создании телеграмм бота, помогающего в обработке запросов пользователей по информации оказания товаров и услуг (предоставления выбора вариантов в зависимости от запроса). 
Актуальность:
－	Профилизация поисковых помощников – дробление сфере ботов ассистентов, поисковиках, помощниках (ориентированных на определённые сферы)
－	Клиповое мышление в сети (в данной интерпретации - интерес к коротким и субъективно интересным историческим справкам) (функциональные возможности предоставления исторических справок Википедии об адресах)
－	Рост популярности ТГ как социальной сети и количества ботов-помощников в нём


Задачи для реализации проекта “Тематическая система поиска”:
1.	Создание ТГ бота
2.	Создание базы данных и методов работы с ней
3.	Написание логики обработки запросов
4.	Создание сценариев и структуры ответа на запрос
5.	Проработка сценариев взаимодействия с пользователем (оформление бота и его особенностей общения с пользователем
В результате работы над проектом, реализация задач распределилась на несколько файлов и их структур:

1.	tg_template.py – Создание каркаса ТГ бота (Написание основных функциональных возможностей бота и его взаимодействия с пользователем)

2.	db/system_users.db – База с данными о пользователях

3.	data – Папка с написанием структур базы данных 
a.	user_data.py – таблица данных о пользователе, 
b.	request_history.py – таблица с данными о запросах пользователей
c.	db_session.py – установление связи с файлом *.db
d.	__all_models.py – наследование всех таблиц базы данных

4.	branching_bot_responses.py – Вынесенные ответы ТГ бота на сценарии запросов пользователя (содержит списки с вариациями ответов на запросы пользователей для недопущения однотипности общения с ботом)

5.	logical_framework.py – Логика обработки запросов пользователей и формирование ответов на них (Основной класс - Multiple_analysis, основные функциональные возможности: синтез и распознавание речи, извлечение смысловой части запроса пользователя, преобразование ответов для работы каркаса ТГ бота)

6.	system_functions.py – Файл содержащий «системные» функции, классы, значения (часто используемые в одном или нескольких файлах и вынесенные в файл, для упрощения структуры и оптимизации логической части кода)
