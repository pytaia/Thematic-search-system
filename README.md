Идея:
Создание телеграмм бота, помогающего в обработке запросов пользователей по  информации оказания товаров и услуг (предоставления выбора вариантов в зависимости от запроса)


Функции/структура работы:
1.) Хранение базы данных организаций (добавление, обновление, удаление)
2.) Обработка запросов пользователей (ограниченное число комманд и текстовый ввод, голосовой?)
3.) Обработка запроса пользователя (выделение смысловой части/сущности запроса)
4.) Поиск по базе данных организаций/мест удавлетворяющий запрос пользователя
5.) Вывод пользователю результатов поиска по базе данных на основе его запроса в удобной для него форме (стилизованный список, отметка на карте, голосовое сообщение?)
6.) Сохранение Кеша (запросов, адресов, контекстная реклама для ТГ?)
7.) Обновление данных об организациях через запросы API


Задачи/направления работы:
1.) Создание ТГ бота
2.) Создание базы данных и методов работы с ней
3.) Прописание логики обработки запросов
4.) Создание сценариев и структуры ответа на запрос
5.) Проработка дзайна
6.) Дополнительные функции 


Информация о БД:
1.) Подразделение на базы (данные о пользователе и данные о организации)
2.) Вынесение большого структурированного перечня информации в таблицы, ссылка на них в я ячейках


Хранимые данные (приблизительная структура) :
БД1 т1-(Организации): ссылка на запрос API
БД2: т1-(Данные о пользователе): Логин ТГ, имя в системе, история адресов поиска, т2-(кеш запросов): Дата и время, запрос пользователя, ответ системы
